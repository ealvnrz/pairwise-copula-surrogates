# Pairwise Copula Surrogates

This repository contains current research code for deterministic local
surrogates in pairwise copula criteria. The workflows cover two worked
settings:

- a flexible Clayton-like pairwise criterion with an Appell `F_4` local
  bottleneck;
- a semiparametric spatial factor-copula criterion with an exact-by-quadrature
  local evaluator.

The repository is organized as an analysis project rather than an R package.
It ships the active source code and the main reproducibility artifacts needed
to inspect or rerun the workflows.

## Repository structure

```text
pairwise-copula-surrogates/
|-- README.md
|-- .gitignore
|-- run_pipeline.R
|-- src/
|   |-- core/
|   |-- setup/
|   |-- utils/
|   `-- workflows/
|-- results/
|   |-- figures/
|   |-- summaries/
|   `-- objects/
```

- `src/core/`: exact local evaluators, transformed-coordinate maps, surrogate
  constructors, and criterion wrappers.
- `src/setup/`: shared project loader and path resolver used by the workflow
  scripts.
- `src/utils/`: diagnostics, plotting helpers, timing helpers, and simulation
  utilities.
- `src/workflows/`: runnable workflows for grid construction, fitting,
  benchmarks, diagnostics, and stress checks.
- `results/objects/`: reusable precomputed inputs such as local reference
  bundles, fitted surrogates, and benchmark objects consumed by later
  workflows.
- `results/summaries/`: CSV summaries produced by the workflows.
- `results/figures/`: PNG figures generated by the scientific workflows.

## Source modules

### `src/core/`

- `clayton_core.R`: flexible Clayton-like local evaluator, transformations, and
  exact table builders.
- `spatial_factor_core.R`: factor-copula local evaluator, transformations, and
  benchmark helpers.
- `surrogates.R`: spline and Chebyshev fitting and prediction helpers.
- `reduced_wpl.R`: reduced and practical criterion wrappers plus optimization
  utilities.

### `src/utils/`

- `diagnostics.R`: timing summaries, plotting helpers, scaling summaries, and
  reusable diagnostics.
- `simulation.R`: simulation utilities for the Example 1 and Example 2 designs.

### `src/setup/`

- `project_setup.R`: resolves the repository root, sources the modules, and
  routes outputs to `results/figures`, `results/summaries`, or
  `results/objects`.

## Results produced by each workflow

Each workflow writes to one of three locations:

- `results/objects/` for reusable precomputed inputs needed by later workflows;
- `results/summaries/` for CSV summaries;
- `results/figures/` for PNG figures.

Representative outputs include:

- exact local grids and fitted surrogate objects;
- local accuracy summaries and pointwise comparisons;
- reduced and practical benchmark summaries;
- scaling summaries with optimizer counts;
- clipping, derivative, and reference-depth diagnostics;
- factor-copula refinement, benchmarking, and reuse summaries.

## Precomputed reproducibility assets

The repository ships precomputed outputs so that the workflows can be inspected
without rerunning the full pipeline. In particular:

- reusable precomputed objects are kept only when later workflows read them
  directly;
- stress-fit objects for the free-shape Clayton check are distributed under
  `results/objects/02_spline_fit_stress.rds` and
  `results/objects/03_chebyshev_fit_stress.rds`.

## Requirements

The workflows assume an R environment with:

- `GeoModels`
- `pracma`

Base R packages such as `graphics`, `grDevices`, `splines`, `stats`, `tools`,
and `utils` are used directly and are not listed separately.
